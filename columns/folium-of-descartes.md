# [こばのページ](../../index.html)/[東大入試数学過去問解答例](../index)/[コラム](./index)/$x^3+y^3=3xy$ のとき、$x+y$ の最大値は?

## 式変形
いつものように、 $P_1: \exists x \ldotp \exists y \ldotp x^3 + y^3 = 3xy \land k = x + y$ を量化子消去して、 $x+y$の取り得る値の範囲を求める方針で進めよう。

$s = x + y, t = xy$ という変形を行う。 $\exists x \ldotp \exists y \ldotp s = x + y, t = xy$ は $s^2 \geq 4t$ と同値なので、 $P_1$ は以下の $P_2$ と同値である:

$$P_2: \exists s \ldotp \exists t \ldotp s(s^2-3t) = 3t \land k = s \land s^2 \geq 4t$$

$s$ を消去することで、以下の $P_3$ と同値であることがわかる。

$$P_3: \exists t \ldotp k(k^2-3t) = 3t \land k^2 \geq 4t$$

$k(k^2-3t) = 3t$ は $3t(k+1) = k^3$ と同値なので、 $k \neq -1 \land t =  \dfrac{k^3}{3(k+1)}$ と同値である。これを $k^2 \geq 4t$ に代入することで (等式で変数を消す)、

$$P_4: k \neq -1 \land k^2 \geq \dfrac{4k^3}{3(k+1)}$$

と同値であることがわかる。これで量化子は消去できた。

解答するためにはもう少し単純化する必要がある。
- $k \gt -1$ のときは $3k^2(k+1) \geq 4k^3$ と同値であり、これを変形すると $-k^3+3k^2 \geq 0$ なので $k \leq 3$ と同値である。
- $k \lt -1$ のときは $3k^2(k+1) \leq 4k^3$ と同値であり、これを変形すると $-k^3+3k^2 \leq 0$ なので $k = 0 \lor k \geq 3$ と同値である。 (これは矛盾している。)

以上をまとめると、 $P_4$ は $P_5: -1 \lt k \le 3$ と同値である。よって $k$ の最大値は 3 である。

ちなみに、曲線$x^3+y^3=3xy$はデカルトの正葉線と呼ばれている。
