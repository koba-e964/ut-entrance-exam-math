## まとめ
単に不等式の証明をするだけなら不要。($1+t\le e^t$ など)

最大値・最小値を求める場合は必要なこともあるかもね。

## 不等式の証明

例えば、「 $x, y \gt 0$ のとき $(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \ge 8$ を示せ。」という問題があったとき、以下の解法は妥当である。

$x,y,\dfrac{1}{x}, \dfrac{4}{y}$ はすべて正であるから、相加・相乗平均の関係より、

$$\dfrac{x + y}{2} \ge \sqrt{xy}, \dfrac{1}{2}\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \ge \sqrt{\dfrac{1}{x} \cdot \dfrac{4}{y}} = \dfrac{2}{\sqrt{xy}}$$

これから、

$$x + y \ge 2\sqrt{xy}, \dfrac{1}{x} + \dfrac{4}{y} \ge \dfrac{4}{\sqrt{xy}}$$

がいえるので、両方とも両辺が正であることに注意すると、左辺同士と右辺同士を掛けて

$$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \ge 8$$

を得る。 Qed.

これの「等号成立条件」を考えると、 $x = y \land \dfrac{1}{x} = \dfrac{4}{y}$ だが、そのような $x,y$ は存在しない。それにもかかわらず、普通の数学においてはこの不等式は正しいとみなされる。

数学というのはそういうルールなのでそれに順応するしかない。仮に $\ge 8$ というのが「8 という値を取り得る必要がある」という意味だったら、数学はもっと複雑怪奇になってしまい手に負えなくなる。

## 最大・最小の証明


ここで、最大値・最小値の定義を振り返ろう。集合 $S$ の最小値が $x$ であるというのは、以下の 2 つを同時に満たすことだ。

- $x \in S$ つまり、$x$ は $S$ の要素である
- $\forall y \in S\ldotp y \ge x$ つまり、$S$ のどんな要素 $y$ も $x$ 以上である

上の例において、「$x, y \gt 0$ のとき $(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ の最小値を求めよ」という問題だったならば、仮に最小値が 8 であることを証明するのであれば示すべきことは 2 つある。

$S$ を、$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ が取り得る値の集合としよう。これは $S = \lbrace k \mid \exists x \gt 0\ldotp \exists y \gt 0\ldotp k = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \rbrace$ というふうに書ける。

- $8 \in S$ というのは、論理式で表すと、 $\exists x \gt 0\ldotp \exists y \gt 0\ldotp 8 = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ である。
- $\forall y \in S\ldotp y \ge 8$ というのは、論理式で表すと、 $\forall k. (\exists x \gt 0\ldotp \exists y \gt 0\ldotp k = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)) \Rightarrow k \ge 8$ となる。 これを同値変形すると $\forall x \gt 0. \forall y \gt 0 . (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \ge 8$ となる。 TODO

2番目は上で示したことだが、1番目は成り立たない。よって最小値は8ではない。

$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \ge 8$ (真) と、「$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ の最小値は 8 である」 (偽) の区別をすることは、数学の理解・不等式の理解において極めて重要だ。


## じゃあ範囲はどうやって言うの?

$x \ge 8$ が「$x$ は 8 以上のすべての実数を取り得る」という意味ではないというのは上の議論でわかったと思う。

じゃあどういえばいいのか?

### (1) 数式にこだわる

数式で言うなら、集合からはなかなか逃げられない。「取り得る値の範囲」というのは集合であり、不等号を使っても集合を限定することはできないからだ。
集合の記法で言うのであれば、 $x \ge 8$ というのは $\lbrace x \mid \exists y\ldotp P(x,y)\rbrace \subseteq [8, \infty)$ と同値であり、こういった記号をいくら使っても「求めたい集合はこの区間の部分集合である」といったことしか言えない。

集合の記法および半開区間の記号を使って $\lbrace x \mid \exists y\ldotp P(x,y)\rbrace = [8, \infty)$ のように言うしかない。これは高校数学の範囲を超えるが数学としては妥当だ。 

今回の場合なら、問題の命題を論理式で書いて、 $\lbrace k \mid \exists x \gt 0\ldotp \exists y \gt 0\ldotp k = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)\rbrace = [9, \infty)$ と書くことになる。

集合を嫌い論理式で全て書くという立場なのであれば、 $\exists x \gt 0\ldotp \exists y \gt 0\ldotp k = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right) \Leftrightarrow k \ge 9$ でもよいだろう。このやり方なら集合からは逃げられるが、論理式からは逃げられない。

### (2) 言葉を使っても良い
言葉で説明しても良いのであれば、「$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ の取り得る値の範囲は $9$ 以上のすべての実数。」などと書けば良い。

- 「$(x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)$ は $9$ 以上のすべての実数になり得る。」は、$\lbrace k \mid \exists x \gt 0\ldotp \exists y \gt 0\ldotp k = (x + y)\left(\dfrac{1}{x} + \dfrac{4}{y}\right)\rbrace \supseteq [9, \infty)$ という主張なので、集合のイコールになっておらずダメ。

## とは言うものの
[拡散的思考と収束的思考](./boyaki)の話にもあるように、拡散的思考ではいろいろな考えをすることが大事だ。

等号成立条件を軸にして考えるのは有効なことが多い。例えば「すべての実数 $a,b,c$ に対して$a^2 + b^2 + c^2 \ge ab + bc + ca$が成立することを示せ。」という問題について考えよう。

- 例: $a^2 + b^2 + c^2 \ge ab + bc + ca$ を示したい。 $a = b = c$ のとき等号が成立するので、これが等号成立条件になるような変形を考えよう。左辺から右辺を引くと $(a-b)^2/2 + (b-c)^2/2 + (c-a)^2/2$ になる。これはどう見ても 0 以上だし、等号成立条件とも整合している。

答案を書く段階では収束的思考を使うことになるが、その場合には上でも言ったように等号成立条件を書く必要はない。

- 答え: 左辺から右辺を引いたものは $(a-b)^2/2 + (b-c)^2/2 + (c-a)^2/2$ である。実数の2乗は 0 以上であるため、これも 0 以上である。よって $(左辺) \ge (右辺)$ が成り立つ。

## 最小値を与える $x$ の値は必要か?
- 存在を示す必要はあるが、値そのものは必要ない。
- 存在を示す一番単純なやり方は、値そのものを示すことだ。
- 一方で、存在を示せるが具体的な値を出すのが難しいこともある。それならそれでよい。
  - <https://x.com/f_sei/status/2061960570090537458> において、$\|x^3+x+1\|=0$ を満たす実数 $x$ の存在を示すのは容易である。 ($g(x) := x^3 + x+ 1$ と置くと、 $g(-1)=-1\lt 0, g(0)=1\gt 0$ であり、$g$が連続関数であることと中間値の定理から $-1\lt x \lt 0$ を満たすある $x$ で $g(x) = 0$ となる。) 一方で、具体的に求めるのは難しい。
