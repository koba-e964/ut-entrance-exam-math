# Repository Notes

- Keep commit messages short for routine page additions. For example, use `Add 2025/s3` for a single exam-page addition.
- When adding or publishing an exam page, also add the page link to `index.md`.

### User-authored math commentary style

- When imitating the user's Japanese math-solution blockquote commentary, keep the voice terse and technique-oriented. Prefer phrases like "こういうのは隣接する平方数で挟むのが典型。" and pattern-first explanations like "(2 次式) = (平方数) であれば，2 次式を平方完成して移項して因数分解するのが典型。" Avoid casual agent-like phrasing such as "一番楽そう" when the user has not used that tone.
